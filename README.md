## 📄 Overview

**ResuScan** is a modern, minimal web UI for resume scanning and **ATS (Applicant Tracking System)** style analysis. Built with **Vite + Tailwind CSS**, it provides a fast, responsive interface designed to be easily extended with an AI-powered resume parsing backend for keyword matching, skill extraction, and compatibility scoring.

---

## ✨ Features

- 📤 **Resume Upload** — Drag-and-drop or file picker for resume submission
- 🔍 **ATS Analysis UI** — Visual score breakdown and keyword matching interface
- 🎨 **Clean Minimal Design** — Professional, distraction-free interface
- 📱 **Fully Responsive** — Optimized for all screen sizes
- ⚡ **Lightning Fast** — Vite-powered development and build
- 🤖 **AI-Ready Architecture** — Plug-in backend for resume parsing & ML analysis

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Jixu-Dev/ResuScan.git
cd ResuScan

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
