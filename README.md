# ResuScan

ResuScan is a modern and responsive web UI built for a resume scanning / ATS-style application.  
It is fast, minimal, and designed to be easily extended with backend or AI-based resume analysis.

## 🚀 Features
- Fast development using Vite
- Clean and minimal UI
- Fully responsive design
- Easy to integrate with resume parser or AI backend

## 🛠️ Tech Stack
- Vite
- Tailwind CSS
- JavaScript
- HTML & CSS

## 📦 Installation

```bash
git clone https://github.com/Jixu-Dev/ResuScan.git
cd ResuScan
npm install
npm run dev

Open http://localhost:5173 in your browser.
